Ajuste Planilha Projeção de Gastos

Ferramentas para ajustar e exportar a planilha de projeção de gastos com dados do sistema.

O arquivo baixado preserva a estrutura original (botões com Office Script, desenhos e validações). Arquivos .xlsm com macros VBA são suportados; .xlsx não pode conter macros VBA. Após atualizar o sistema, reprocesse a planilha — arquivos gerados antes da correção podem abrir com erro de formato.
Ajuste Completo da Planilha (todos os processos)

Envie a planilha uma única vez para executar, em sequência, os três ajustes: Reunião, NF por Requisição de Compra e demais dados por Requisição de Compra.

{% csrf_token %}
Formatos aceitos: .xlsx, .xls, .xlsm
Limpar
Orientação

Ordem de execução:

  1. GASTO CONFIRMADO ← classificação da reunião (por ID)
  2. NF PARA LANÇAMENTO e NF DE SERVIÇO RECEBIDA ← Controle RC/NF (por REQUISIÇÃO DE COMPRA / RC)
  3. PEDIDO DE COMPRA, SOLICITANTE, ORDEM DE SERVIÇO, DATA ABERTURA DA REQUISIÇÃO e OBSERVAÇÃO ← Controle RC/NF (por REQUISIÇÃO DE COMPRA / RC)

Apenas células vazias são preenchidas — valores já existentes não são alterados.

  Células preenchidas pelo sistema são destacadas em amarelo no arquivo gerado.

Processos individuais
Ajustar e Preencher Planilha com Dados da Reunião de Previsão de Gastos

Envie a planilha de projeção de gastos para preencher automaticamente a coluna GASTO CONFIRMADO com a classificação definida na reunião de previsão de gastos.

{% csrf_token %}
Formatos aceitos: .xlsx, .xls, .xlsm
Limpar
Orientação

O sistema localiza as colunas ID e GASTO CONFIRMADO na planilha enviada e preenche essa última com a classificação da reunião cadastrada no banco de dados. Apenas células vazias são preenchidas — valores já existentes não são alterados.

  Células preenchidas pelo sistema são destacadas em amarelo no arquivo gerado.

Ajuste e Preenchimento de NF baseado no número da Requisição de Compra

Envie a planilha de projeção de gastos para preencher automaticamente os dados de Nota Fiscal com base no número da Requisição de Compra.

{% csrf_token %}
Formatos aceitos: .xlsx, .xls, .xlsm
Limpar
Orientação

O sistema compara o REQUISIÇÃO DE COMPRA da planilha com o campo RC do Controle RC/NF. Quando os números coincidem:

  • preenche NF PARA LANÇAMENTO: SERVIÇO OU MATERIAL (ou NF: SERVIÇO OU MATERIAL) com nf_servico ou nf_saida;
  • preenche NF DE SERVIÇO RECEBIDA com SIM.

Apenas células vazias são preenchidas — se a linha já tiver valor em alguma dessas colunas, o sistema não substitui o conteúdo existente.

  Células preenchidas pelo sistema são destacadas em amarelo no arquivo gerado.

Preencher demais dados baseado no Número da REQUISIÇÃO de Compra:

Envie a planilha de projeção de gastos para preencher automaticamente os demais campos com base no número da Requisição de Compra (coluna REQUISIÇÃO DE COMPRA), relacionado ao campo RC do Controle RC/NF.

{% csrf_token %}
Formatos aceitos: .xlsx, .xls, .xlsm
Limpar
Orientação

O sistema compara o REQUISIÇÃO DE COMPRA da planilha com o campo RC do Controle RC/NF. Quando os números coincidem, preenche:

  • PEDIDO DE COMPRA ← pedido
  • SOLICITANTE ← solicitante
  • ORDEM DE SERVIÇO ← os
  • DATA ABERTURA DA REQUISIÇÃO ← data_rc
  • OBSERVAÇÃO ← status

Apenas células vazias são preenchidas — valores já existentes não são alterados.

  Células preenchidas pelo sistema são destacadas em amarelo no arquivo gerado.
