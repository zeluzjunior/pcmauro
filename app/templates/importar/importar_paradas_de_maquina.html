Formatos aceitos: CSV (.csv) com delimitador ponto e vírgula (;)
Quando marcado, todos os registros atuais de paradas de máquina serão removidos e somente os dados do arquivo enviado serão mantidos. Use quando o novo arquivo já contiver o histórico completo (evita duplicados).
Quando marcado, apenas registros que ainda não existem na tabela serão importados. Registros duplicados serão ignorados.
Quando marcado, registros existentes serão atualizados com os dados do arquivo. Nota: Se "Apenas adicionar novos registros" estiver marcado, esta opção será ignorada.
Instruções
Formato do Arquivo:

O arquivo CSV deve usar delimitador ponto e vírgula (;) e conter as seguintes colunas (primeira linha como cabeçalho):

  • UNID - Código da Unidade
  • NOME_UNIDADE - Nome da Unidade
  • LINHA_PRODUCAO - Código da Linha de Produção
  • DESCR_LINHA_PRODUCAO - Descrição da Linha de Produção
  • TURNO - Turno (A, B, C, etc.)
  • DATA - Data da parada (formato: DD/MM/YYYY) - obrigatório
  • CÓD. ITEM - Código do Item
  • DESCR. ITEM - Descrição do Item
  • CÓD. GRUPO DE RECURSO - Código do Grupo de Recurso
  • GRUPO RECURSO - Descrição do Grupo de Recurso
  • CÓD. PARADA - Código da Parada
  • DESCR. PARADA - Descrição da Parada
  • NRO - Número
  • CÓD. RECURSO - Código do Recurso
  • DESCR. RECURSO - Descrição do Recurso
  • HORARIO INICIAL - Horário inicial (formato: HH:MM)
  • HORARIO FINAL - Horário final (formato: HH:MM)
  • DIF. HORA - Diferença em horas (decimal)
  • CAPACIDADE - Capacidade (decimal)
  • MOTIVO - Motivo da parada
  • AÇÃO - Ação tomada
Observações:
  • A primeira linha do arquivo deve conter os cabeçalhos das colunas
  • O campo DATA é obrigatório para cada registro
  • O sistema identifica registros duplicados pela combinação de Data + Código Recurso + Horário Inicial
  • O sistema aceita valores decimais no formato brasileiro (ex: 0,06666667) ou formato americano (ex: 0.06666667)
  • O sistema suporta arquivos CSV com diferentes encodings (latin-1, iso-8859-1, utf-8, cp1252) e tenta detectar automaticamente o encoding correto
