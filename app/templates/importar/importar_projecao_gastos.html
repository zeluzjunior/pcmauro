Importar Projeção de Gastos

Importe dados de projeções de gastos através de arquivo Excel

Selecionar Arquivo
{% csrf_token %}
Formatos aceitos: Excel (.xlsx, .xls, .xlsm)
O arquivo deve conter uma planilha chamada "GASTOS" com as colunas: SETOR, SOLICITANTE, FORNECEDOR NOME FANTASIA, FORNECEDOR CNPJ, DESCRIÇÃO DO SERVIÇO, VALOR TOTAL, PREVISÃO P/ EXECUÇÃO, USO CONTÁBIL, NÚMERO DA NOTA FISCAL, ORDEM DE SERVIÇO, DATA DE ABERTURA DA REQUISIÇÃO, NÚMERO DA REQUISIÇÃO DE COMPRA, NÚMERO DO PEDIDO DE COMPRA, SERVIÇO CONCLUÍDO, NF DE SERVIÇO RECEBIDA, NF ENVIADA PARA LANÇAMENTO.
Quando marcado, projeções existentes (identificadas pelo ID do Excel) serão atualizadas com os dados do arquivo. Quando desmarcado, apenas novas projeções serão criadas.
Instruções
Formato do Arquivo:
  • O arquivo deve ser um arquivo Excel (.xlsx, .xls ou .xlsm)
  • Deve conter uma planilha chamada "GASTOS"
  • A primeira linha deve conter os cabeçalhos das colunas
Colunas Esperadas:
  • SETOR - Setor responsável
  • SOLICITANTE - Solicitante (CNPJ)
  • FORNECEDOR NOME FANTASIA - Nome fantasia do fornecedor
  • FORNECEDOR CNPJ - CNPJ do fornecedor
  • DESCRIÇÃO DO SERVIÇO - Descrição do serviço
  • VALOR TOTAL - Valor total do serviço
  • PREVISÃO P/ EXECUÇÃO - Previsão de execução (ex: "OUTUBRO / 2025")
  • USO CONTÁBIL - Uso contábil
  • NÚMERO DA NOTA FISCAL - Número da nota fiscal
  • ORDEM DE SERVIÇO - Número da ordem de serviço
  • DATA DE ABERTURA DA REQUISIÇÃO - Data de abertura
  • NÚMERO DA REQUISIÇÃO DE COMPRA - Número da requisição (usado como identificador único)
  • NÚMERO DO PEDIDO DE COMPRA - Número do pedido
  • SERVIÇO CONCLUÍDO - Data de conclusão do serviço
  • NF DE SERVIÇO RECEBIDA - Data de recebimento da NF
  • NF ENVIADA PARA LANÇAMENTO - Data de envio para lançamento
Importante: O campo ID do Excel é usado como identificador único. Se uma projeção com o mesmo ID já existir no banco de dados e a opção "Atualizar registros existentes" estiver marcada, os dados serão atualizados. Caso contrário, a linha será ignorada.
