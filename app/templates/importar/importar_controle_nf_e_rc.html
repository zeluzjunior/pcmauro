Como os duplicados são detectados:
  • Por ID (Prioridade): O sistema primeiro verifica se o ID do Excel já existe no banco de dados. Este é o identificador único principal.
  • Por RC (Fallback): Se não houver ID no Excel, o sistema verifica se o RC já existe no banco de dados (compatibilidade com dados antigos).
  • Por NF Saída (Fallback): Se não houver ID nem RC, o sistema verifica se a NF Saída já existe no banco de dados (compatibilidade com dados antigos).
  • Campos adicionais: O sistema também verifica se outros campos como Pedido coincidem para confirmar a duplicação.

Instruções
Formato do Arquivo:
  • O arquivo deve ser um arquivo Excel (.xlsx, .xls ou .xlsm)
  • Deve conter uma planilha chamada "CONTROLE RC E NF"
  • A linha 1 deve estar vazia
  • A linha 2 contém o título
  • A linha 3 deve conter os cabeçalhos das colunas
  • Os dados começam na linha 4
Colunas Esperadas:
  • ID - Identificador único do registro (obrigatório)
  • SOLICITANTE - Nome do solicitante
  • EMPRESA - Nome da empresa
  • NF SAÍDA - Número da nota fiscal de saída
  • TORNO? - Indicador de retorno (ex.: SIM/NÃO)
  • DESCRIÇÃO DO SERVIÇO - Descrição do serviço
  • C.A/RATEIO - Centro de Atividade/Rateio
  • USO - Uso contábil
  • QUEM ABRIU A RC - Pessoa que abriu a requisição
  • ORÇAMENTO - Informações do orçamento
  • O.S - Número da ordem de serviço
  • CLASSIF. - Classificação
  • JUSTIFICATIVA CLASSIFICAÇÃO - Justificativa
  • SPAF0009 - Acesso portaria p/ classif. 5 e 8 - Informação SPAF0009
  • RC - Número da requisição de compra (identificador único)
  • DATA RC - Data da requisição de compra
  • PEDIDO - Número do pedido
  • VALOR TOTAL DO PEDIDO - Valor total
  • PREVISÃO PARA USO - Data de previsão
  • NF SERVIÇO - Número da NF de serviço
  • NF RETORNO E DATA LANÇAMENTO - NF retorno e data
  • CNPJ AURORA - CNPJ Aurora
  • SIMPLES NACIONAL - Simples Nacional
  • VALOR NF - Valor da nota fiscal
  • EMISSÃO - Data de emissão
  • INCLUSÃO 198 - Data de inclusão 198
  • STATUS - Status do registro
  • OBS - Observações
  • SALDO RESIDUAL PEDIDO - Saldo residual
Importante: O campo ID é o identificador único principal usado para identificar e diferenciar registros. Se um registro com o mesmo ID já existir no banco de dados e a opção "Atualizar registros existentes" estiver marcada, os dados serão atualizados. Caso contrário, a linha será ignorada. Se o ID não estiver presente no Excel, o sistema tentará usar RC ou NF Saída como fallback (compatibilidade com dados antigos).
